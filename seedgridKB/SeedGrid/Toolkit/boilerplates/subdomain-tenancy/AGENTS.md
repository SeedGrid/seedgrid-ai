# Instruções

- Use Git Bash.
- Trabalhe na ordem backend, admin e frontend.
- Preserve Java 21 e as versões da referência `../login-tenancy`; não faça upgrades.
- Use a extensão subdomain-tenancy já instalada no `.m2` e seu BOM.
- É proibido alterar as extensões em `seedgrid-platform/java`; consulte os fontes apenas para leitura.
- Reutilize os endpoints, DTOs, serviços e dependências transitivas das extensões.
- Mantenha no host somente configuração, providers concretos, adaptações de UI e domínio próprio.
- Não copie segredos, chaves privadas, builds ou dependências instaladas de outro projeto.
- Não inicie serviços Podman.
- Consulte os READMEs dos três projetos para configuração e validação.
