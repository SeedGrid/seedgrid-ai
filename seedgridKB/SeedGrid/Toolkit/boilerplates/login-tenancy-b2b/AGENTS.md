# AGENTS

Guia de entrada do `seedgrid`. Leia as skills antes de mexer no código.

## Skills

Ficam em `.ai/skills/`, uma pasta por skill, com `SKILL.md` dentro.
Catálogo completo: `.ai/skills/README.md`.

- Reuse uma skill existente antes de criar outra.
- Não duplique a mesma skill em `~/.codex/skills` e no repositório.
- Skills valem pra este projeto — o `platform-monorepo` foi descontinuado,
  não é fonte de verdade pra nada aqui.
