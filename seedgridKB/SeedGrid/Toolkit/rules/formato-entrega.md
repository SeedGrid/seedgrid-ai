# Formato de entrega dos papéis

Todo papel encerra o trabalho com uma entrega neste formato. Não inclua raciocínio interno; descreva fatos verificáveis.

```markdown
## Resultado
O que foi feito, em 1 a 5 frases.

## Arquivos alterados
- caminho/do/arquivo — o que mudou (ou "nenhum")

## Verificações executadas
- comando ou inspeção — resultado (passou/falhou/não executado e por quê)

## Problemas pendentes
- item pendente, risco ou dúvida (ou "nenhum")

## Contexto para a próxima etapa
Informações de que o próximo papel ou o coordenador precisa.
```

Regras:

- Relate falhas como falhas. Verificação não executada deve aparecer como "não executada", com o motivo.
- Não declare algo pronto sem ter verificado; se não foi possível verificar, diga isso.
- Mantenha a entrega curta. Detalhes extensos vão para arquivos referenciados.
