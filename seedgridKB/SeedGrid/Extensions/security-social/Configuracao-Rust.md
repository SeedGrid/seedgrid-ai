# Configuração Rust — `seedgrid-security-social`

Volta para: [[SeedGrid/Extensions/security-social/Rust|Porte Rust do security-social]] · Java: [[SeedGrid/Extensions/security-social/Configuracao|Configuração do security-social (Quarkus)]]

## 1. Cabeçalho

| Item | Valor |
|---|---|
| Crate / pacote | diretório `rust/seedgrid-rust-crate-security-social`, pacote Cargo `seedgrid-security-social`, lib `seedgrid_security_social` |
| Struct de config | `SocialConfig` (com um `ProviderConfig` por provedor listado) — `src/config.rs` |
| Mecanismo | variáveis de ambiente lidas com `std::env::var` em `SocialConfig::from_env()` e `ProviderConfig::from_env(id)`; o host ou o teste também pode montar as structs à mão. Valor em branco conta como ausente |
| Falha | `from_env` não falha: valores inválidos são ignorados (ficam os padrões). Quem recusa subir é o `config_validator.rs` (provedor listado sem credencial, segredo placeholder, segredos curtos) |
| Origem (caminho base) | todas as origens abaixo são relativas a `rust/seedgrid-rust-crate-security-social/` |

Dialeto único: só o nome `SEEDGRID_SECURITY_SOCIAL_*` (e `SEEDGRID_SECURITY_FRONTEND_*`) é lido; não há alias `SECURITY_*`. Durações usam `seedgrid_security::config::parse_duration_to_seconds`.
